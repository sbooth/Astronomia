# Astronomia

Astronomy in Swift.

## Installation

### Swift Package Manager

Add a package dependency to https://github.com/sbooth/Astronomia in Xcode.

### Manual or Custom Build

1. Clone the [Astronomia](https://github.com/sbooth/Astronomia) repository.
2. `swift build`.
